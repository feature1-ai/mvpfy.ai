Frames for the walkthrough GIF in the project README.

Drop screenshots of the running app here, named so they sort in the order you
want them shown — `01-plan.png`, `02-board.png`, `03-overview.png` — then run:

    npm run media:gif

That writes `docs/media/mvpfy.gif`, which the README points at. A screen
recording works too: save it as `docs/media/source.mov` and run the same
command (frames win if both are present).

On macOS, ⇧⌘4 then Space captures one window; ⇧⌘5 records one.
